## ✨ Features (លក្ខណៈពិសេស)
- **110+ Dynamic Visualizer Presets**: Waveform, Circular Spectrum, Cyberpunk Bars, Liquid Neon, Vinyl LP, Golden Mandala, Cassette, Retro Boombox...
- **Multi-Track Continuous Playlist**: ចាក់បទចម្រៀងតៗគ្នាក្នុង Album ជាមួយ Drag-and-Drop រៀបលំដាប់បទ។
- **Smart Typography**: គាំទ្រពុម្ពអក្សរខ្មែរស្អាតៗជាច្រើន (Kantumruy Pro, Battambang, Moul, Siemreap...) និងពុម្ពអក្សរអន្តរជាតិ (Outfit, Orbitron, Cinzel...) ជាមួយ Effects មាស (Gold), Neon Glow, 3D Shadow, Chrome...
- **Auto Track Highlight Overlay**: បង្ហាញបញ្ជីបទលើអេក្រង់វីដេអូ និងលោត Highlight លើបទដែលកំពុងចាក់ស្វ័យប្រវត្តិ។
- **Custom Image Uploader**: អាចដាក់រូប Background ផ្ទាល់ខ្លួន (ជាមួយ Blur & Darkness dim) និងរូប Cover កណ្តាលផ្ទាល់ខ្លួនបាន។
- **Flexible Aspect Ratios**: 16:9 (YouTube/TV), 9:16 (TikTok/Reels/Shorts), 1:1 (Instagram), 4:5 (Portrait Feed)។
- **In-Browser Video Exporter**: ទាញយកជាវីដេអូ WebM/MP4 បានភ្លាមៗដោយមិនបាច់ប្រើ Server។
- **Ultra-Responsive Design**: សមាមាត្រស្អាតលើគ្រប់ Computer, Laptop (1366x768, 1440x900, 1920x1080) និង Mobile។
